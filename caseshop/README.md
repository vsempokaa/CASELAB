# CaseLab — лендінг магазину чохлів для телефонів

Навчальний проєкт. Основа — безкоштовний шаблон [Forty by HTML5 UP](https://html5up.net/forty) (CC BY 3.0).

- `index.html` — сторінка лендінгу
- `assets/css/custom.css` — власні стилі поверх шаблону
- `assets/js/shop.js` — демо-кошик і події Google Analytics 4 (view_item → add_to_cart → begin_checkout → purchase)
- `images/` — оптимізовані SVG-зображення товарів (разом ~19 КБ)

Увага! Цей веб-сайт є навчальним проєктом, створеним виключно з освітньою метою в межах навчального курсу. Сайт не здійснює комерційної діяльності, не надає платних послуг і не призначений для отримання прибутку.
